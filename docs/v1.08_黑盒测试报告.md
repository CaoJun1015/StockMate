## 四、发现的问题清单

### 问题 #1（Suggestion）

| 项目 | 内容 |
|------|------|
| **严重程度** | Suggestion（建议优化） |
| **文件** | `src/models/database.py` 第 974-992 行 |
| **函数** | `get_customer_stats()` |
| **描述** | SQL 查询不排除已取消报价，`total_quotes`、`total_amount`、`total_profit` 均包含 `status='已取消'` 的记录 |
| **根因** | SQL 只有 `WHERE q.customer_id = ?`，缺少 `AND q.status != '已取消'` |
| **影响** | 客户统计页面显示的金额和利润偏高（包含了已取消的报价） |
| **修复建议** | 在 SQL 的 WHERE 子句加上 `AND q.status != '已取消'`，与其他统计函数（如 `get_customer_balance`）保持一致 |
| **备注** | 这不是本次修改引入的问题，是原有逻辑。是否修改取决于业务需求——如果已取消报价有财务意义（如退款对账），则保留现状更合理 |
