# 价税分离功能 — 操作指南

> 适用版本：v1.10+
> 什么时候用：当进货价或销售价涉及含税/不含税口径不一致时

---

## 一句话说明

> 系统默认用「售价 - 进价」算利润。如果你需要区分含税/不含税，勾选对应选项即可。

---

## 场景 1：不做价税处理（95% 的情况）

什么也不用做，和以前一样。新建报价时不勾任何选项，利润按「售价 - 进价」计算。

---

## 场景 2：需要价税分离（5% 的情况）

### 2.1 设置客户默认税率

1. 打开「客户管理」Tab
2. 新增或编辑客户
3. 在「默认税率」下拉框中选择 **8%** 或 **13%**
4. 保存

> 客户税率保存后，以后给这个客户新建报价时，税率会自动填入。

### 2.2 新建报价时设置价税

1. 在机型管理中选择产品 → 点击「报价」
2. 填写报价金额和数量
3. **税率**：自动从客户带入，也可手动改（选 8% / 13% / 无）
4. **勾选关键选项**：

| 选项 | 什么时候勾选 |
|------|-------------|
| ☑ 进价含税 | 进货成本是含税价（如供应商报价 1500 含税） |
| ☑ 售价含税 | 你报给客户的是含税价（如给客户报 1500 含税） |
| 都不勾 | 进价和售价都是不含税口径，利润 = 售价 - 进价 |

5. 保存

### 2.3 常见组合

| 进价 | 售价 | 操作 |
|------|------|------|
| 不含税 | 不含税 | 都不勾（和以前一样） |
| 含税 | 含税 | 两个都勾 |
| 含税 | 不含税 | 只勾「进价含税」 |
| 不含税 | 含税 | 只勾「售价含税」 |

---

## 场景 3：查看税后利润

报价记录表中，利润列会自动显示税后调整值。

**举例**：
- 进价 1500（含税 13%）= 不含税成本约 1327 元
- 售价 1450（不含税）
- 勾选「进价含税」，不勾「售价含税」
- 系统显示利润：1450 - 1327 = **+123 元**

如果没勾选，系统会显示 1450 - 1500 = **-50 元**（看起来亏损，实际盈利）。

---

## 场景 4：修改历史报价的税率

如果之前忘了设置税率，可以补：

1. 在报价记录表中右键点击该报价 → 编辑
2. 设置税率和含税选项
3. 保存，利润自动更新

---

## 场景 5：不需要了，恢复原样

把税率改为「无」，两个勾选取消即可。利润恢复为「售价 - 进价」。

---

## 注意事项

1. **税率是每个报价独立存储的**。客户税率变了，历史报价不受影响。
2. **只影响利润计算**。售价、进价、收款金额等原始数据不会改变。
3. **不影响出库和收款流程**。价税分离只是在计算利润时多做一个调整。
4. **如果不确定要不要用，就不勾**。不勾 = 和以前完全一样。
