# 调货助手 v1.10 — 手动测试手册

> 请按顺序逐条执行，每条记录 ✅ 或 ❌

---

## 准备

1. 双击 `调货助手 v1.10.exe`
2. 确认标题栏显示 **"调货助手 v1.10"**
3. 如果已有数据，先记下当前的数据库状态（批次数量、供应商欠款等）

## 一、自动备份（2条）

### B-01 启动时自动备份
- [ ] 关闭软件，重新打开
- [ ] 打开 `data/backups/` 目录
- [ ] 确认出现新的备份文件（文件名格式：`diaohuo_backup_YYYYMMDD_HHMMSS.db`）
- [ ] 文件和 `diaohuo.db` 大小相近

### B-02 备份文件不重复
- [ ] 关闭软件，再打开一次
- [ ] 确认 `backups/` 目录下出现了第二个备份文件（时间戳不同）
- [ ] 两个备份文件都存在，没有被覆盖

## 二、模糊搜索（5条）

### S-01 搜机型内存
- [ ] 切换到"机型管理"标签
- [ ] 在搜索框输入 `16G`
- [ ] 确认所有内存为 16G 的机型都被筛选出来

### S-02 搜机型显卡
- [ ] 清空搜索框，输入 `4060`
- [ ] 确认所有显卡包含 4060 的机型被筛选出来

### S-03 搜机型硬盘
- [ ] 清空搜索框，输入 `512G`
- [ ] 确认所有硬盘为 512G 的机型被筛选出来

### S-04 搜客户微信
- [ ] 切换到"客户管理"标签
- [ ] 在搜索框输入某个客户的微信号（部分即可）
- [ ] 确认该客户被筛选出来

### S-05 搜供应商电话
- [ ] 切换到"上游管理"标签
- [ ] 在搜索框输入某个供应商的电话号（部分即可）
- [ ] 确认该供应商被筛选出来

## 特别说明

### 收款提醒（R-01）手动准备数据的方法

如果数据库中没有超过7天的已出库订单，可以这样准备：

1. 用记事本或其他工具打开 `data/diaohuo.db`（SQLite 数据库）
2. 找到一条已出库且未收满的报价，记下它的 `id`
3. 执行 SQL（需要 SQLite 工具或让我帮你改）：
   ```sql
   UPDATE quotes SET quote_date = '2026-07-09' WHERE id = 你的报价ID;
   ```
4. 重新打开软件，该报价就会显示为红色

或者直接告诉我，我帮你改数据库中的日期。
