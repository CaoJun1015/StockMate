# v1.16.1 简洁版：财务操作与 Qt 打包修复

本分支基于仓库的 `v1.16` 标签，保存 2026-11-17 交付的简洁版业务代码和 Qt 打包修复，不替换 v1.17.x 的开发历史。

## 行为变化

- 财务页面调整为「应收应付、日常收支、利润分析、流水审计」，默认显示应收应付。
- 自动准备内部记账账户，收付款、批次、退货操作无需选择资金账户；隐藏手动资金调整、账户转账等入口。
- 保留复式记账、业务对账及历史数据；已启用财务的数据库不重置账户余额。
- 支持补录历史日期和金额小数；更正历史收付款时保留已取消订单状态，并依据出库快照维护订单状态。
- 新增客户、供应商显式初始化分单位余额，兼容旧数据库字段默认值。
- 导出业务收支和利润分析，不展示资金账户余额。

## QtWidgets DLL 错误

原 EXE 在导入 `PyQt6.QtWidgets` 时退出，尚未进入数据库初始化。Qt 主库和 Windows 插件均为 x64、6.11.1.0；错误来自构建 PATH 混入的 Poppler `icuuc.dll`。该 DLL 缺少 Qt6Core 所需的 20 个 Windows ICU 导出函数。

`build.spec` 在依赖分析前限定 Qt、Python、Windows 的 DLL 搜索路径，随后检查所有二进制来源，拒绝混入其他工具目录的运行库。构建依赖由 `requirements-release.lock` 固定。

## 构建

验证环境：Windows x64、Python 3.11.9、PyQt6 6.11.0、Qt 6.11.1、PyInstaller 6.21.0。

在仓库目录执行 PowerShell：

```powershell
py -3.11 -m venv .venv311
.\.venv311\Scripts\python.exe -m pip install -r requirements-release.lock
.\.venv311\Scripts\python.exe -m PyInstaller --clean --noconfirm build.spec
```

输出为 `dist/调货助手 v1.16.1 简洁版.exe`。正常运行时读取 EXE 同目录的 `data/diaohuo.db`；可以通过 `DIAOHUO_DATA_DIR` 指定隔离的数据目录。仓库不包含实际业务数据库。
