# 调货助手 v1.09 — 手动测试用例

> 请按顺序逐条执行，每条测试记录 ✅ 或 ❌

---

## 准备工作

1. 双击打开 `调货助手 v1.09.exe`
2. 确认标题栏显示 **"调货助手 v1.09"**
3. 添加一个测试机型：系列=测试，CPU=i5，内存=16，硬盘=512，显卡=集显，屏幕=14

---

## 一、入库流程（3条）

### TC-01 添加供应商
- [ ] 点击"上游管理"标签 → 添加供应商
- [ ] 名称=测试供应商，微信=test_wx，QQ=123456，电话=13800000000
- [ ] 确认供应商列表中出现该记录

### TC-02 入库批次
- [ ] 点击"库存管理"标签 → 添加批次
- [ ] 选择刚创建的机型，购入价=5000，数量=10，入库日期=今天
- [ ] 选择供应商"测试供应商"
- [ ] SN列表填写：`SN001,SN002,SN003,SN004,SN005,SN006,SN007,SN008,SN009,SN010`
- [ ] 确认批次列表出现，剩余=10

### TC-03 验证供应商欠款
- [ ] 回到"上游管理"，查看"测试供应商"
- [ ] 确认欠款余额显示为 ¥50,000（5000×10）

---

## 二、报价 + 出库流程（5条）

### TC-04 创建报价
- [ ] 点击"报价管理" → 新建报价
- [ ] 选择批次，报价数量=2，报价单价=5500，日期=今天
- [ ] 确认报价列表出现，状态=**待确认**

### TC-05 出库（状态机守卫测试）
- [ ] 选中该报价 → 点击"出库"
- [ ] 出库SN输入：`SN001,SN002`
- [ ] 确认状态变为**已出库**
- [ ] 回到"库存管理"，确认批次剩余=8

### TC-06 验证报价SN独立
- [ ] 回到"报价管理"，查看该报价
- [ ] 确认 SN 列显示 `SN001,SN002`
- [ ] 回到"库存管理"，确认批次 SN 列仍然显示全部10个SN（不被出库修改）

### TC-07 状态机守卫：已出库不能重复出库
- [ ] 选中已出库的报价 → 点击"出库"
- [ ] 确认弹出提示"不允许出库"或类似警告

### TC-08 状态机守卫：已出库不能直接改回"待确认"
- [ ] 选中已出库的报价 → 尝试通过编辑按钮修改状态
- [ ] 确认无法从"已出库"直接跳回"待确认"

---

## 三、收款流程（4条）

### TC-09 全额收款
- [ ] 选中已出库的报价 → 点击"收款"
- [ ] 输入金额=11000（5500×2），方式=微信
- [ ] 确认状态变为**已收款**，收款金额显示 ¥11,000

### TC-10 状态机守卫：已收款不可再操作
- [ ] 选中已收款的报价 → 尝试出库/收款
- [ ] 确认被拒绝

### TC-11 部分收款测试（用新报价）
- [ ] 新建报价：同一机型，数量=1，单价=6000
- [ ] 出库（SN=SN003）
- [ ] 收款：金额=3000（不够全额6000）
- [ ] 确认状态仍为**已出库**（不是"已收款"），收款金额显示 ¥3,000

### TC-12 修改/删除收款后状态保持
- [ ] 找到 TC-11 的报价，在收付款记录中找到该笔收款
- [ ] 删除这笔收款
- [ ] 确认状态**保持"已出库"**（不会回退到"待确认"）
- [ ] 确认收款金额变为 ¥0

---

## 四、取消订单测试（3条）

### TC-13 取消已出库订单 → 库存回补
- [ ] 新建报价：同一机型，数量=2，单价=5500
- [ ] 出库（SN=SN004,SN005）
- [ ] 确认批次剩余从 5 降到 3
- [ ] 取消该订单
- [ ] 确认批次剩余**回补到 5**
- [ ] 确认报价 SN 列变为空

### TC-14 取消未出库订单 → 无副作用
- [ ] 新建报价：同一机型，数量=1，单价=6000，状态=待确认
- [ ] 记录当前批次剩余
- [ ] 取消该订单
- [ ] 确认批次剩余不变，供应商欠款不变

### TC-15 已取消订单不能再操作
- [ ] 选中已取消的报价 → 尝试出库/收款
- [ ] 确认被拒绝

---

## 五、删除测试（3条）

### TC-16 删除已出库报价 → 库存回补
- [ ] 新建报价，出库后记录批次剩余
- [ ] 删除该报价
- [ ] 确认批次剩余回补

### TC-17 删除批次 → 供应商欠款回滚
- [ ] 到"库存管理"，找到之前创建的批次
- [ ] 记录供应商当前欠款
- [ ] 删除该批次
- [ ] 确认供应商欠款**减少**了该批次的金额（5000×数量）

### TC-18 删除机型 → 级联删除
- [ ] 到"机型管理"，删除测试机型
- [ ] 确认关联的批次、报价全部被删除
- [ ] 确认供应商欠款已回滚

---

## 六、客户统计测试（2条）

### TC-19 新客户统计 → 返回0而非空白
- [ ] 添加一个新客户"测试客户B"（不要给TA创建任何报价）
- [ ] 查看该客户的统计信息
- [ ] 确认总金额=0，利润=0（不是空白或报错）

### TC-20 已取消报价不计入统计
- [ ] 添加"测试客户C"
- [ ] 给TA创建3笔报价，取消其中1笔
- [ ] 查看统计信息
- [ ] 确认金额和利润**只包含2笔**（不包含已取消的）
